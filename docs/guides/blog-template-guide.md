# 📝 Guía de Plantilla para Blogs - YourCVPassport

Esta guía contiene todas las instrucciones y ejemplos para crear contenido de blog profesional y bien estructurado.

---

## 📦 Cajas de Contenido Especiales

### 💡 Caja de Consejo (Tip Box)
**Uso:** Para consejos profesionales y mejores prácticas.
**Color:** Verde

**Sintaxis:**
```
:::tip
Tu consejo profesional aquí. Puede ser de múltiples líneas.
:::
```

**Ejemplo:**
```
:::tip
El formato de tu CV es tu primera impresión. Un diseño profesional puede aumentar tus posibilidades de ser contactado en un 40%.
:::
```

---

### ℹ️ Caja de Información (Info Box)
**Uso:** Para datos importantes, estadísticas o información clave.
**Color:** Azul

**Sintaxis:**
```
:::info
Tu información importante aquí. Ideal para estadísticas y datos verificados.
:::
```

**Ejemplo:**
```
:::info
El 75% de los CVs son filtrados automáticamente por sistemas ATS antes de llegar a un reclutador humano.
:::
```

---

### ⚠️ Caja de Advertencia (Warning Box)
**Uso:** Para advertencias, errores comunes que evitar o información crítica.
**Color:** Amarillo

**Sintaxis:**
```
:::warning
Tu advertencia importante aquí. Usa esto para errores comunes que evitar.
:::
```

**Ejemplo:**
```
:::warning
Nunca uses más de 2 fuentes diferentes en tu CV. La simplicidad transmite profesionalismo.
:::
```

---

### 📋 Caja de Ejemplo (Example Box)
**Uso:** Para ejemplos prácticos, comparaciones o casos de uso.
**Color:** Morado

**Sintaxis:**
```
:::example
Tu ejemplo práctico aquí. Perfecto para comparaciones antes/después.
:::
```

**Ejemplo:**
```
:::example
❌ Malo: "Trabajé en ventas"
✅ Bueno: "Incrementé las ventas en un 35% en 6 meses implementando estrategias de prospección digital"
:::
```

**Uso:** Para imágenes con texto descriptivo debajo.

**Sintaxis:**
```

**Ejemplo:**
```

## 📋 Listas

### Lista con Viñetas
**Sintaxis:**
```
- Primer elemento
- Segundo elemento
- Tercer elemento
```

**Ejemplo:**
```
Un CV profesional debe tener:

- Información de contacto clara y actualizada
- Resumen profesional que capte la atención
- Experiencia laboral con logros cuantificables
- Educación y certificaciones relevantes
```

**Nota:** Las viñetas aparecerán con flechas azules (▸) automáticamente.

---

### Lista con Negritas
**Sintaxis:**
```
- **Título en negrita**: Descripción del elemento
- **Otro título**: Otra descripción
```

**Ejemplo:**
```
- **Información de contacto**: Clara y actualizada
- **Resumen profesional**: Que capte la atención en 10 segundos
- **Experiencia laboral**: Con logros cuantificables
```

## ✨ Mejores Prácticas

### Estructura Recomendada de un Artículo

```
Título del Artículo

Introducción que enganche al lector y presente el tema.

:::tip
Un consejo inicial relevante para captar la atención.
:::

Sección Principal 1

Contenido de la primera sección con información valiosa.

- Punto importante 1
- Punto importante 2
- Punto importante 3

![Imagen relevante](url){caption:Descripción de la imagen}

:::example
Ejemplo práctico relacionado con esta sección.
:::

Sección Principal 2

Más contenido valioso con información práctica.

:::info
Estadística o dato importante.
:::

Conclusión

Resumen de los puntos clave y llamada a la acción.

:::example
Recordatorio final o mensaje para llevar.
:::
```

---

## 🎨 Consejos de Estilo

1. **Usa cajas con moderación**: No más de 3-4 cajas por artículo
2. **Varía los tipos de cajas**: Alterna entre tip, info, warning y example
3. **Imágenes de calidad**: Usa Unsplash para imágenes profesionales gratuitas
4. **Párrafos cortos**: Máximo 3-4 líneas por párrafo
5. **Listas efectivas**: Usa listas para información fácil de escanear
6. **Negritas estratégicas**: Resalta solo lo más importante
7. **Captions descriptivos**: Usa captions para dar contexto a las imágenes

## 🔗 Recursos Útiles

### Bancos de Imágenes Gratuitas
- **Unsplash**: https://unsplash.com/ (Profesional, alta calidad)
- **Pexels**: https://pexels.com/ (Variedad amplia)
- **Pixabay**: https://pixabay.com/ (Gran cantidad de recursos)

### Dimensiones Recomendadas
- **Imagen destacada del artículo**: 1200x630px
- **Imágenes dentro del contenido**: Mínimo 800px de ancho
- **Formato**: JPG optimizado o WebP

## 🚀 Checklist Pre-Publicación

Antes de publicar tu artículo, verifica:

- [ ] Título atractivo y descriptivo
- [ ] Introducción que enganche en los primeros 2-3 renglones
- [ ] Al menos 2-3 cajas de contenido (tip, info, warning, example)
- [ ] Mínimo 2-3 imágenes relevantes
- [ ] Todas las imágenes tienen captions descriptivos
- [ ] Listas con viñetas para información fácil de escanear
- [ ] Negritas en conceptos clave
- [ ] Párrafos cortos (3-4 líneas máximo)
- [ ] Conclusión clara con llamada a la acción
- [ ] Sin símbolos # o ## sueltos
- [ ] Meta título y meta descripción optimizados para SEO
